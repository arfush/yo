# Yonime

**Yonime** — уютная аниме-библиотека и плеер для Windows. Добавляй тайтлы по ссылке AnimeLIB, выбирай озвучку и серию, смотри с продолжением с места — а история, обложки и прогресс останутся на твоём компьютере.

> **Yonime никак не связан с AnimeLIB.** Это независимый неофициальный проект, сделанный пользователями для удобства. Он не представляет AnimeLIB, не является его официальным клиентом и не действует от его имени.

> **Проект полностью навайбкожен.** Весь код — от первой до последней строки — написан ИИ. Ни единой строчки кода человек здесь не написал. Если ты ищешь пример классической человеческой разработки, это не он. Если тебе нужен рабочий проект, который целиком собрали нейросети, — добро пожаловать.

## Возможности

### Библиотека

- Добавление тайтлов по ссылке AnimeLIB или по slug — ссылки с зеркал тоже подходят.
- История просмотра с обложками, статусами и количеством серий.
- Перетаскивание тайтлов, чтобы выстроить собственный порядок.
- Удаление с отменой в течение 10 секунд — на случай, если рука дрогнула.
- Очистка всей истории — тоже с возможностью отмены.
- Статусы «завершено», «онгоинг» и «анонс»; для анонсов показывается отдельное сообщение.

### Страница тайтла

- Постер, русское и оригинальное название, статус.
- Список озвучек с отметками о пропущенных сериях и о сериях, доступных только через Kodik.
- Сетка серий с быстрым выбором нужной.
- Выбор качества: 720p, 1080p, 1440p или 2160p.
- Сохранение выбранной озвучки и серии, чтобы вернуться к ним позже.

### Просмотр

- Воспроизведение через mpv в отдельном окне с фирменным заголовком Yonime.
- Автоматическая очередь серий и плавный переход к следующей.
- Предзагрузка соседних серий, чтобы переключение было быстрым.
- Продолжение с последней позиции и сохранение прогресса.
- Приоритет прямого плеера AnimeLIB и автоматический фолбэк на Kodik, когда это нужно.
- Главы опенинга, эндинга, рекапа и превью — можно прыгать по ним в mpv.
- Приложение уходит с экрана на время просмотра и возвращается после закрытия плеера.

### Удобство

- Первый запуск сам подготовит всё необходимое: Chromium и mpv.
- Авторизация проходит на сайте AnimeLIB — приложение не просит пароль.
- Работа в трее: закрытие окна сворачивает Yonime, а не завершает его.
- Один запущенный экземпляр — второй запуск просто открывает уже работающее приложение.
- Автоматическая проверка обновлений и установка новой версии из GitHub Releases.
- Тёмный интерфейс, шрифт Inter, аккуратные анимации, котодевочка и аниме-подсказки в строке ввода.
- Русский интерфейс.

### Горячие клавиши

| Клавиши | Действие                                     |
| --- |----------------------------------------------|
| `Ctrl+K` | Перейти к строке ввода                       |
| `↑` / `↓` | Выбрать тайтл в истории                      |
| `Enter` | Открыть выбранный тайтл или загрузить ссылку |
| `Esc` | Отменить загрузку                            |

## Как начать

1. Скачай последний релиз Yonime со страницы **Releases** этого репозитория.
2. Запусти приложение. При первом запуске оно само скачает Chromium и mpv, а затем предложит войти на AnimeLIB.
3. Авторизуйся на открывшемся сайте, вставь ссылку на тайтл в строку ввода и нажми `Enter`.
4. Выбери озвучку, серию и качество — и нажми «Смотреть».

Приложение поддерживает Windows 10 и 11. Сборки публикуются для x64, ARM64 и x86.

## Данные и приватность

- История, прогресс, настройки и обложки хранятся локально на твоём компьютере.
- Пароль от AnimeLIB вводится только на сайте AnimeLIB; Yonime его не видит и не хранит.
- Приложение не собирает телеметрию и не отправляет данные о просмотре куда-либо, кроме сервисов, необходимых для работы библиотеки и плеера.
- Удаление истории в приложении удаляет и локальные записи о ней.

## Честно о проекте

Yonime — эксперимент в жанре «вайб-кодинг». Здесь нет команды разработчиков, нет код-ревью от людей и нет ни одной строки, написанной человеческой рукой. Всё приложение — интерфейс, логика, интеграции, тесты, этот README и даже шутки в подсказках — создано ИИ. Человек ставил задачи, запускал сборки и проверял результат, но код писал не он.

Поэтому:

- где-то могут встречаться странные решения;
- что-то может сломаться после обновления AnimeLIB;
- баги возможны, и это нормальная часть эксперимента.

Если проект работает и приносит удовольствие — значит, вайб-кодинг справился.
